# Welcome

This repository is designed to help a new user python coder give python a shot.

If you are reading this you are hopefully interested in giving coding a shot in python. Whether that is for a particular goal or just to give it a go, please read through the following guide of how to setup and how to use python.

## What is Python

Python is a high level coding language. It can be used for many purposes from phone apps to automation of a regular task. Python is consider to be a high level coding language which means it is closer to human language than the lower level machine code which can be completely incomphrensible (think ones and zeroes). This makes it a great place to dip your toes in the water of coding.
